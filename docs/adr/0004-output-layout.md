# ADR 0004: Каталог прогона по timestamp и единый output_manager

- **Статус:** принято
- **Дата:** 2026-11-08
- **Связанные файлы:** `injector3d/output_manager.py`,
  `injector3d/config.py`

## Контекст

Раньше номер пункта плана попадал в пути, имена файлов и логи. Это
связывало артефакты с исторической нумерацией и мешало повторным прогонам.

## Решение

- Один прогон — один каталог `<база>/<YYYYMMDD_HHMM>/`.
- `<база>` — `--output-dir` или `config.OUTPUT_DIR`.
- Имена файлов формирует только `injector3d/output_manager.py`.
- Номер пункта плана не используется в путях и именах.
- Для ring-режима геометрическая метка `a<угол>_n<N>` входит в `tag`.
- PNG отслеживаются git; `.blend`, `.blend1`, `.json`, `.log`, `.glb`
  в `output/` игнорируются.

## Последствия

- Повторный прогон не перезаписывает старый каталог.
- Шарды синхронизируются через `--timestamp`.
- Пакетный прогон использует
  `<output-dir>/<batch>/<series>/`, `batch_manifest.json` и `logs/`.
