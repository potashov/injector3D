# Architecture Decision Records

> Короткие записи о ключевых архитектурных решениях. ADR объясняет
> «почему», а не дублирует код или отчёты. Статусы: `принято`,
> `заменено`, `устарело`.

| ADR | Решение | Статус |
|---|---|---|
| [0001](0001-liquid-in-world-coordinates.md) | жидкость строится в мировых координатах | принято |
| [0002](0002-camera-attached-and-azimuth-tilt.md) | камера привязана к трубке, наклон по азимуту | принято |
| [0003](0003-postprocess-worker-and-bbox.md) | worker-постобработка и bbox до overlay | принято |
| [0004](0004-output-layout.md) | каталог прогона по timestamp, имена через output_manager | принято |
| [0005](0005-dataset-export-after-render.md) | датасет собирается после рендера из manifest | принято |

Новый ADR добавляется, когда решение меняет архитектуру, инварианты или
формат вывода. Если решение заменено, старый ADR не удаляется: ему
ставится статус `заменено` и ссылка на новый.
