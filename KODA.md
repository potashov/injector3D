# KODA.md — injector3D

> Headless-Blender проект: генерирует 3D-сцену трубки с жидкостью и
> рендерит её под заданным числом ракурсов (N+1: вертикаль + N плоскостей
> наклона, п. 4.5).
> Это **не обычный Python-пакет**: модули импортируют `bpy`, поэтому
> запускать их можно только внутри Blender.

---

## Обзор проекта

**injector3D** — проект для фотореалистичной генерации 3D-рендеров
цилиндрической прозрачной трубки (⌀19×92 мм), заполненной жидкостью
на 50 %. Серия строится по N+1 кадрам: вертикаль + N плоскостей наклона
при фиксированном угле `θ` (п. 4.5). Цель — получить серию кадров,
совпадающих с реальным фотокадром `06120.png` от камеры OV5693
(1.3 мм, дисторсия +0.66).

**Ключевые особенности:**
- Мениск решается через солвер Юнга-Лапласа (РК4 + бисекция по ζ(0)),
  а не подбирается эмпирически.
- Свободная поверхность жидкости всегда горизонтальна в мировых
  координатах, даже при наклоне трубки.
- Камера во всех режимах привязана к трубке (`attach_camera_to_tube`),
  поэтому трубка в кадре не меняется — наклоняется только жидкость.
  Разные кадры серии даёт тип поворота трубки: наклон в плоскости
  азимута `Rz(φ)·Ry(θ)·Rz(φ)⁻¹`, а не вращение связки вокруг Z.
- Рендер на GPU (CUDA) с авто-фоллбэком на CPU.

**Технологический стек:**
- Blender 5.2.3 LTS (локальная headless-сборка в `blender-5.2.3-linux-x64/`)
- Cycles (GPU/CUDA или CPU)
- Python-модули `injector3d/` (bpy, bmesh, mathutils)
- Постобработка: `python3` + PIL/numpy/scipy

## Сборка и запуск

### Blender (указатель)

```bash
BL=./blender-5.2.3-linux-x64/blender
```

> **Важно:** используйте локальную сборку 5.2.3 из корня проекта. Код
> сохраняет совместимость с 4.3.2 через ветки API композитора.

### Основные команды

```bash
# Рендер пункта плана (номер → output/<N>/ и префикс файлов)
$BL --background --python injector3d/create_scene.py -- 4

# Кадр под референс 06120 (1200×1200, белый фон, сдвиг вправо 105 px)
$BL --background --python render_reference.py

# Числовая самопроверка жидкости (единственный автотест)
$BL --background --python check_liquid.py

# Диагностика CUDA / GPU
$BL --background --python check_cuda.py
$BL --background --python check_build_cuda.py
$BL --background --python gpu_info.py
```

**Параметр шага:** номер пункта после `--` управляет не только именами
файлов, но и составом сцены: жидкость появляется с пункта 2, материалы —
с пункта 4. Без номера используется `1`.

### Проверка

Тестового фреймворка нет. Проверка = успешный прогон
`check_liquid.py` (assert'ы + код возврата) и рендер без исключений.

├── liquid.py            # Объём жидкости: мировой горизонт + мениск
├── meniscus.py          # Солвер Юнга-Лапласа (профиль мениска)
├── materials.py         # Пластик PMMA + жидкость с поглощением
├── scene.py             # Сцена, камера, свет, CUDA-устройства
├── render.py            # Ракурсы, дисторсия, постобработка
└── create_scene.py      # Entry-point (сборка сцены, валидация, рендер)

render_reference.py      # Одиночный кадр под 06120.png
postprocess_reference.py # Белый фон, масштаб/сдвиг (system python3)
check_liquid.py          # Числовая самопроверка объёма и уровня

### Ключевые компоненты

| Модуль | Назначение |
|--------|-----------|
| `config.py` | Все параметры в мм; перевод в метры через `MM = 0.001` |
| `tube_geometry.py` | 39 точек профиля × 192 сегмента → 7106 вершин, 100 % manifold |
| `liquid.py` | `bmesh.ops.bisect_plane` в мировых координатах; кэш мениска |
| `meniscus.py` | Осесимметричное решение Юнга-Лапласа, ΔV ≈ 293.65 мм³, подъём у стенки 3.034 мм |
| `materials.py` | PMMA (IOR 1.49) + вода (IOR 1.33, density 20.0, оттенок 73,73,58) |
| `render.py` | Ракурсы, наклон по азимуту (`tilt_matrix`), дисторсия, постобработка |
| `create_scene.py` | Порядок: сцена → геометрия → валидация → жидкость/материалы → рендер |

### Жидкость и мениск

- Меш жидкости = полость трубки ∩ `{z_world <= level}`. Строится в
  **мировых координатах**, пересобирается на каждый наклон через
  callback `on_tilt` из `render.py`.
- Объект жидкости **не** дочерний трубке — иначе уровень наклонялся бы
  вместе с ней.
- Свободная поверхность = мениск: срез на уровне кромки контакта +
  радиальная сетка (`MENISCUS_RINGS = 80`). При наклоне кромка
  эллиптическая, но поверхность остаётся горизонтальной.
- Для клина у дна / перелива — плоский fallback.

### Камера

- Референс `06120`: OV5693, объектив 1.3 мм, сенсор 3.6288×2.7216 мм,
  дистанция 46 мм, `Distortion=+0.66`, roll +1.5°, f/2.8.
- `SCENE_CAMERA` ссылается на `REFERENCE_CAMERA` — основная серия
  использует ту же оптику.
- Камера привязана к трубке через `attach_camera_to_tube()` — и в
  `render_tube()` (п. 1–4), и в `render_ring()` (п. 4.5). Привязка
  делается на этапе вертикальной сцены, поэтому в цикле рендера достаточно
  менять `tube.matrix_world`: положение, наведение и ракурс камеры
  пересчитывает Blender.
- Разные кадры серии 4.5 даёт не открепление камеры, а тип поворота:
  `tilt_matrix(θ, φ) = Rz(φ)·Ry(θ)·Rz(φ)⁻¹` (наклон в плоскости азимута
  вокруг `TILT_PIVOT_Z_MM = 46 мм`). Нормаль горизонта жидкости в системе
  трубки `R(φ)⁻¹·e_z` обходит конус с полууглом θ. Старый `AzimuthRig`
  с `Rz(φ)·Ry(θ)` сокращал φ — кадры были идентичны.
- `SCENE_POSTPROCESS`: `shift_x_px=105`, `target_height_px=0`. Сдвиг
  совпадает с референсом: камера привязана к трубке, поэтому трубка
  целиком в кадре во всех ракурсах.

### Рендер

- Разрешение: 1200×1200, RGBA, `film_transparent=True`.
- Cycles: 128 сэмплов, `time_limit=75с`, каустики включены.
- В п. 4.5 — N+1: вертикаль + N плоскостей наклона при фиксированном
  угле `θ`; подробности — `reports/step4.5.md` (§15–16).
- Денуазинг: OpenImageDenoise в 5.2.3 доступен, но включается условно
  через `_safe_set` для совместимости со старыми headless-сборками.
- AgX + `AgX - Medium High Contrast` применяются корректно.
- Жидкость: оттенок по замеру RGB 73,73,58 задаётся как *тон*
  (B/R = 58/73), а не как абсолютный цвет — иначе жидкость пропустит
  ~7 % света и станет почти чёрной. `Density` Volume Absorption = 20.0:
  Cycles считает поглощение на метр, а слой жидкости — 19 мм.

## Особенности Blender / окружения

1. **Настройки Cycles** — только через
   `bpy.context.preferences.addons['cycles'].preferences`, не
   `preferences.cycles`.
2. **MeshEdge.link_faces** и **Mesh.bound_box** в 4.3 недоступны —
   работать через `bmesh`.
3. **OpenImageDenoise** в 5.2.3 доступен, но денуазинг включается
   условно через `_safe_set` — в старых сборках OIDN мог отсутствовать.
4. **CUDA** включается для дискретных NVIDIA
   (`config.GPU_DEVICE_FILTER`); если GPU нет — фоллбэк на CPU.
5. **Верх трубки открыт** — boundary-рёбра допустимы только на
   верхней кромке.
6. **Метрический масштаб** — все размеры в мм, перевод через `MM = 0.001`.
   Смешивать мм и Blender-юниты нельзя.

## Конвенции

- **Язык:** документация, комментарии, отчёты и коммиты — по-русски.
- **Коммиты:** стиль `Пункт N: ...`, акцент на «почему», а не «что».
- **Порядок работы:** сначала код + `check_liquid.py`, затем перерендер
  `output/<N>/`.
- **Согласованность:** не менять геометрию/материалы без повторного
  рендера — PNG должны соответствовать коду.
- **Зазор жидкости:** `CLEARANCE = 0.02 мм` — предотвращает z-fighting
  в Cycles между жидкостью и стенкой трубки.
