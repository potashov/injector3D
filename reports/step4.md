# Отчёт по пункту 4: Материалы — прозрачный пластик и жидкость

**Дата:** 2 ноября 2026
**Статус:** ✅ Завершён
**Коммиты:** `900b6ce`, `a81c14f`, `e91005c`

## Цель

Дать трубке оптические свойства прозрачного пластика (PMMA), а жидкости —
свойства воды с объёмным поглощением света, чтобы рендер показывал
преломление, каустики и блики, а не белый цилиндр.

## Что сделано

### 1. Модуль `injector3d/materials.py`

**`create_material_plastic(name="Plastic")`** — прозрачный пластик:

| Параметр | Значение | Обоснование |
|---|---|---|
| Transmission Weight | 1.0 | материал полностью прозрачный |
| IOR | 1.49 | PMMA/акрил (из `config.IOR_PMMA`) |
| Roughness | 0.0 | полированная стенка, резкие блики |
| Base Color | (0.95, 0.95, 0.95) | почти нейтральный, чуть тёплый |

**`create_material_liquid(name="Liquid")`** — жидкость:

| Параметр | Значение | Обоснование |
|---|---|---|
| Transmission Weight | 1.0 | прозрачная |
| IOR | 1.33 | вода |
| Roughness | 0.0 | спокойная поверхность |
| Volume Absorption Color | (0.8, 0.9, 1.0) | голубоватый сдвиг |
| Volume Absorption Density | 0.5 | заметное, но не плотное поглощение |

### 2. Модуль `injector3d/liquid.py`

`create_liquid(name, fill_level)` — цилиндр жидкости внутри трубки:
- радиус `INNER_RADIUS - CLEARANCE`, дно на `BOTTOM_THICKNESS + CLEARANCE`;
- `CLEARANCE = 0.02 мм` (20 мкм в метрах).

**Зачем зазор.** В Cycles строго совпадающие поверхности дают z-fighting и
артефакты рефракции. 20 мкм при масштабе сцены неразличимы глазу, но
разрешают конфликт поверхностей.

`liquid_volume_mm3(fill_level)` — расчётный объём, понадобится на пункте 2
для подбора уровня по целевому объёму.

### 3. Пробный рендер и устранённые ошибки Blender 4.3

| Проблема | Решение |
|---|---|
| `ShaderNodeVolumeAbsorption` не имеет входа `Absorption Distance` | используются `Color` + `Density` |
| Объём нельзя подать в `Mix Shader` | `Volume` подключается в сокет `Volume` ноды `Material Output` |
| `write_standalone` удалён из оператора | `bpy.ops.render.render(write_still=True)` |
| «Cannot render, no camera» | камера назначается в `scene.camera` |
| `read_factory_settings(use_empty=True)` не создаёт World | мир создаётся явно и привязывается к сцене |
| `use_denoising=True` роняет рендер | денуазинг включается только если денуазер реально доступен |

### 4. Именование рендеров (изменение процесса)

Ранее `create_scene.py` всегда писал в `output/1/`, независимо от того,
какой пункт выполняется — кадры разных пунктов перезаписывали друг друга.
Теперь номер пункта передаётся аргументом после `--`:

```bash
blender --background --python injector3d/create_scene.py -- 4
# → output/4/4_<ракурс>_<YYYYMMDD_HHMMSS>.png
```

Пункт 1 восстановлен отдельным прогоном (`output/1/`, коммит `e91005c`).

Сцена строится по номеру пункта: до пункта 4 рендерится геометрия без
материалов, иначе кадры пункта 1 показывали бы то, чего на том этапе ещё
не существовало.

### 5. `.gitignore`

`output/` убран из игнора, но добавлено `output/**/*.blend`: PNG-рендеры —
результат работы, они в репозитории; `.blend` (~1 МБ каждый) восстанавливаются

## Известное ограничение — переносится на пункт 2

Жидкость сделана **дочерним объектом** трубки, поэтому при наклоне столб
наклоняется вместе с ней, а его верхняя грань остаётся перпендикулярной
оси трубки. Физически поверхность жидкости должна оставаться
**горизонтальной в мировых координатах**.

Это не ошибка материалов, а отсутствие среза плоскостью: ровно этот
механизм — горизонтальная плоскость уровня плюс подбор высоты по целевому
объёму — и есть предмет пункта 2.
