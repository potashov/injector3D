# Референс 06120: камера и дисторсия

## Цель

Подобрать камеру и дисторсию так, чтобы одиночная трубка на кадре
1200×1200 была похожа на трубку из `06120.png` / `06120_mask.png`:

- белый фон;
- трубка сдвинута вправо от центра примерно на 105 px;
- верх трубки обрезан;
- низ кадра — около 75 px;
- ширина у низа — около 240 px, максимальная — около 320–330 px.

Основной пайплайн из 5 ракурсов (`create_scene.py`) не менялся: это
отдельный режим для сравнения с референсом.

## Исходники

| Файл | Размер | Назначение |
|------|--------|------------|
| `06120.png` | 1200×1200 | фотография-референс |
| `06120_mask.png` | 1200×1200 | маска трубки |

По маске: ширина внизу ≈240 px, максимум ≈331 px, нижний отступ 75 px,
верх обрезан. Центр трубки в середине кадра смещён вправо примерно на
111 px, при этом на фотографии есть небольшой наклон (верх правее низа).

## Параметры камеры

| Параметр | Значение |
|----------|----------|
| Сенсор | OV5693 5MP 1/4″, 3.6288×2.7216 мм |
| Пиксель | 1.4 µm |
| Объектив | 1.3 мм M12 |
| Дистанция до оси | 46 мм |
| Положение камеры | `z = 40 мм` |
| Цель камеры | `z = 35 мм` |
| Наклон камеры | вниз на 5 мм |
| Roll | +1.5° |
| Диафрагма | f/2.8 |
| Дисторсия | `Distortion = +0.66` (barrel) |
| Разрешение | 1200×1200 |
| Сэмплы | 128 |
| Сдвиг вправо | +105 px |
| Высота трубки | 1124 px |

Параметры закреплены в `injector3d/config.py` в `REFERENCE_CAMERA`.
Камера настраивается в `render_reference.py`: снимается `TRACK_TO`,
положение и ориентация задаются вручную, чтобы добавить roll.

## Пайплайн

1. Blender рендерит кадр 1200×1200 в RGBA с `film_transparent=True`.
2. В композиторе используется `CompositorNodeLensdist` с
   `use_fit=False` и `Distortion=+0.66`.
3. `postprocess_reference.py` (системный `python3`) заменяет чёрные
   полосы/прозрачные области белым, измеряет высоту трубки, масштабирует
   кадр по вертикали до 1124 px и сдвигает изображение вправо на 105 px.
4. Результат сохраняется в `output/06120/06120_match_<timestamp>.png`.

Постобработка вынесена отдельно, потому что `Lensdist` с `use_fit=False`
оставляет чёрные полосы по краям, а в Blender Python нет PIL/scipy.
Для неё нужны системные `python3`, `PIL`, `numpy`, `scipy`.

## Результат

Файл: `output/06120/06120_match_20261104_194054.png`.

| Метрика | Референс | Рендер |
|---------|----------|--------|
| Ширина bbox | 332 px | 335 px |
| Максимальная ширина | 331 px | 331 px |
| Высота видимой трубки | 1124 px | 1125 px |
| Нижний отступ | 75 px | 75 px |
| Сдвиг центра | ≈+111 px | +105 px |
| Ширина y=10 | 235 px | 228 px |
| Ширина y=100 | 267 px | 278 px |
| Ширина y=468 | 331 px | 331 px |
| Ширина y=1050 | 246 px | 260 px |
| Ширина y=1100 | 163 px | 186 px |

Совпадение по середине и максимуму хорошее. Основное расхождение —
нижняя часть: у референса дно сильнее скруглено, поэтому на тех же
уровнях трубка уже. Это ограничение геометрии дна, а не камеры.

## Ограничения и отличия

- Референс — прозрачная трубка в белом держателе; текущий рендер — тёмная
  трубка на белом фоне. Это различие материалов/освещения, не камеры.
- На референсе центр трубки смещён примерно на +111 px, в рендере
  закреплено +105 px по выбранному варианту.
- Небольшой наклон верх/низ на референсе воспроизведён roll +1.5°,
  но кривизна нижней части всё равно отличается из-за формы дна.
- Чёрные полосы `Lensdist` не являются частью кадра: они заливаются
  белым в постобработке.

## Воспроизведение

```bash
BL=./blender-4.3.2-linux-x64/blender

# Полный рендер + постобработка
$BL --background --python render_reference.py

# Только постобработка уже готового raw-кадра
python3 postprocess_reference.py raw.png final.png --shift 105 --height 1124

# Регрессия жидкости
$BL --background --python check_liquid.py
```

## Файлы

- `injector3d/config.py` — `REFERENCE_CAMERA`, `REFERENCE_RESOLUTION`,
  `REFERENCE_OUTPUT_DIR`.
- `render_reference.py` — рендер raw-кадра с камерой v2.
- `postprocess_reference.py` — белый фон, вертикальный масштаб, сдвиг.
- `output/06120/06120_match_20261104_194054.png` — контрольный кадр.
- `06120.png`, `06120_mask.png` — исходные референс и маска.
