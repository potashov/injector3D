# Смешанный мениск: рабочий clipped-прототип

**Дата:** 8 ноября 2026
**Статус:** рабочий отдельный прототип; текущий `build_liquid()` не изменялся.
**Файлы:**

- `injector3d/meniscus_mixed.py` — солвер и построение крышки;
- `check_meniscus_mixed.py` — автономные проверки;
- `reports/meniscus_mixed_solver_design.md` — исходная концепция и расчёты.

---

## 1. Что реализовано

В отдельном модуле реализованы два пути:

1. **`method='clipped'` — рабочий прототип и значение по умолчанию.**
   Берётся осесимметричный профиль Юнга–Лапласа `zeta(r)` из
   `meniscus.solve_meniscus()`, поверхность `phi(r) = L + zeta(r) - zeta(0)`
   обрезается дном:
   `top(r, theta) = max(phi(r), b(r, theta))`.
   В точках, где `phi < b`, жидкости нет; там поверхность совпадает с дном.
   Смешанная контактная линия получается как пересечение
   `phi(r) = b(r, theta)`.

2. **`method='pde'` — экспериментальный 2D-солвер.**
   Решает линейное уравнение Юнга–Лапласа на полярной сетке с
   obstacle-проекцией и Dirichlet/граничным слоем у стенки. Оставлен для
   дальнейшей разработки; по умолчанию не используется, потому что SOR
   сходится медленно, а постановка краевого условия на стенке ещё не
   доведена до физически точной.

Текущий `build_liquid()` не вызывается и не изменяется.  Интеграция —
отдельный шаг после закрытия ограничений прототипа.

## 2. Алгоритм clipped-прототипа

### 2.1. Геометрия

В локальных координатах трубки:

```text
R   = INNER_RADIUS - CLEARANCE = 9.48 мм
z0  = BOTTOM_THICKNESS + CLEARANCE = 1.02 мм
b(r, theta) = t_z + r·(e_x.z·cos theta + e_y.z·sin theta) + a_z·z0
phi(r)      = L + zeta(r) - zeta(0)
```

`e_x`, `e_y`, `a` — столбцы `matrix_world`; `t_z` — мировая z-трансляция
в мм; `a_z > 0`.

### 2.2. Объём

Для каждого азимута `theta` решается одномерная задача о пересечении
`phi(r)` и линейной по `r` функцией `b(r, theta)`.  Затем интеграл

```text
V = (1/a_z) ∫∫ r·max(phi(r) - b(r, theta), 0) dr dtheta
```

считается по точным интервалам смоченности и квадратуре по `r`.  Это
даёт сходимость по углу лучше 0.01 мм³ уже при 256 азимутах; ранняя
2D-полярная квадратура давала систематическую ошибку до ~5 мм³ из-за
разрыва на контактной линии.

### 2.3. Подбор уровня

`V(L)` монотонно возрастает.  Бисекция по `L` в диапазоне
`[bottom_min - 2, spill_level]`, допуск `0.02 мм³`.

### 2.4. Меш

`build_cap_bmesh()` строит верхнюю менисковую крышку на полярной сетке
`120 × 192` в мировых координатах.  В сухих точках `top = b`, поэтому
крышка непрерывна и замыкается по внешней кромке `r = R`.
Замкнутый объёмный меш пока не реализован: `closed=True` поднимает
`NotImplementedError`.

## 4. Ограничения

1. **Clipped-модель — приближение первого порядка.**
   Поверхность остаётся осесимметричной; 2D-деформация у сухой части
   контактной линии не учитывается.  Краевой угол на дне не задаётся:
   поверхность просто пересекает дно.

2. **Только крышка.**
   Замкнутый меш жидкости (верх + дно + стенка) пока не реализован.
   `closed=True` явно поднимает `NotImplementedError`.

3. **2D-PDE не является рабочим путём.**
   Он оставлен в модуле как эксперимент.  SOR сходится медленно,
   Dirichlet-условие на стенке даёт отличающийся от осесимметричного
   профиль, а Neumann-вариант требует более устойчивого решателя
   (мультигрид/CG) и отдельной проверки краевого угла.

4. **Fast-путь `build_liquid()` не используется.**
   `_MENISCUS_TEMPLATE_CACHE` рассчитан на полный эллипс; для mixed-режима
   нужен отдельный путь, возможно, с кэшем по ориентации и объёму.

5. **Замечание по существующему коду.**
   `meniscus.solve_meniscus()` без явного `contact_angle_deg` падает с
   `NameError: CONTACT_ANGLE_DEG is not defined` (константа не импортирована
   в `meniscus.py`).  Новый модуль всегда передаёт угол явно; текущий код
   не изменялся.

## 5. Следующие шаги

1. Реализовать замкнутый меш жидкости со смешанной контактной линией:
   верх, дно и боковая стенка; проверить `bm.calc_volume()` против
   интеграла объёма.
2. Добавить извлечение контактной линии (стенка + дно) в `info`:
   дуга на стенке, контур на дне, две точки перехода.
3. Довести 2D-солвер: симметричная дискретизация, мультигрид или CG,
   Neumann-условие краевого угла на стенке и на дне.
4. Проверить сходимость по сетке и азимуту, включая `V(θ)=const` для
   целевого объёма.
5. Только после этого интегрировать новый путь в `build_liquid()` в
   переходной зоне, сохранив текущий flat- fallback как страховку.
