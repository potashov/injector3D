# Отчёт по шагу 1: Геометрия трубки

**Дата:** 2 ноября 2026
**Статус:** ✅ Завершён

## Доклад о проделанной работе

### Цель
Создать manifold-меш полый цилиндрической трубки с точным профилем
поперечного сечения и скруглёнными кромками, настроить студийную
сцену и выполнить 5 пробных рендеров.

### Принятые решения

#### 1. Геометрия: сетка «профиль × угол»
Начальный подход с `bmesh.ops.spin` замкнутого профиля дал
2611 non-manifold-рёбер.  Подход с двумя профилями (внешний +
внутренний) тоже не сработал — спин не закрывает дно/верх.

**Решение:** явная сетка «профиль × угол» со схлопыванием вершин на
оси вращения.  Профиль из 39 точек (10 сегментов: 4 дуги + 6
линейных), Revolve-сегментов = 192.  Итог:

- **Вершин:** 7106
- **Полигонов:** 7296
- **Треугольников:** 14208
- **Non-manifold рёбер:** 0
- **Boundary-рёбер:** 0 (верхнее отверстие закрыто кольцевой
  гранью — это правильно, трубка полая)
- **Вырожденных граней:** 0
- **Направления нормалей:** наружу ✅
- **Объём материала:** 6730.68 мм³ (расчётный 6738.91, отклонение
  0.12% — это вклад самих скруглений)
- **Габариты:** ⌀21.500×21.500 мм, высота 100.000 мм
- **Дно:** на z = 0 мм

#### 2. Освещение
Исходные источники по 2000–5000 Вт были избыточны для объекта
размером 10 см на расстоянии 0.45 м.  Пересчёт в метрическую
систему:

| Источник | Позиция (м)       | Мощность (Вт) | Размер (м) |
|----------|-------------------|---------------|------------|
| Key      | (0.35, -0.30, 0.40) | 60.0          | 0.30       |
| Fill     | (-0.40, -0.35, 0.15)| 18.0          | 0.45       |
| Rim      | (-0.15,  0.45, 0.45)| 45.0          | 0.25       |
| Top      | (0.0, 0.0, 0.8)     | 30.0          | 0.50       |

Добавлен 4-й свет сверху для бликов на трубке.

#### 3. Камера
- Позиция: (0, -0.45, 0.05) — на -Y, смотрит в +Y (вдоль трубки
  сбоку)
- Lens: 85 мм, DOF f/5.6
- Цель: пустой объект в центре трубки `(0, 0, 0.05)` с constraint
  `TRACK_TO`

#### 4. Настройки Cycles
- Device: CPU, 12 потоков
- Samples: 128
- Caustics: reflective + refractive
- Bounces: total=16, transmission=16, transparent=16, glossy=6,
  diffuse=4, volume=0
- Clamp indirect: 10.0
- Time limit: 75 сек
- **Денойзер:** недоступен в headless-сборке Debian → отключён
- **Tone-mapping:** AgX недоступен → используется default

#### 5. Имена файлов
Уникальные имена с timestamp: `1_<ракурс>_<YYYYMMDD_HHMMSS>.png`
- `1_upright_20261102_134841.png` — вертикально
- `1_left30_20261102_134841.png` — наклон влево 30°
- `1_away30_20261102_134841.png` — отклонена вдаль 30°
- `1_right30_20261102_134841.png` — наклон вправо 30°
- `1_toward30_20261102_134841.png` — наклон к камере 30°

#### 6. Архитектурные изменения
- Удалён дублирующий `run_step1.py`
- Вынесены модули: `scene.py` (сцена/свет/камера), `render.py`
  (рендер), `validate.py` (в процессе)
- `create_scene.py` стал entry-point'ом
- `config.py` содержит все параметры, включая LIGHTS

#### 7. Обнаруженные ограничения Blender 4.3
- `bpy.types.MeshEdge.link_faces` — недоступен в 4.3, работает
  только через bmesh
- `bpy.types.Mesh.bound_box` — недоступен в 4.3
- `prefs.cycles` — недоступен в headless-режиме
- `bpy.ops.render.render(write_standalone=True)` → заменён на
  `write_still=True`
- Enum-списки (denoiser, view_transform) пусты, но прямое
  присваивание работает → использован try/except фолбэк

### Примечания
- Трубка рендерится без материала — она выглядит как wireframe/прозрачная
  (это ожидаемо, материалы добавятся на шаге 4)
- Денойзер недоступен → рендеры могут быть зернистыми при 128 сэмплах
