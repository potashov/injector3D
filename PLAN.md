# injector3D — План проекта

## Цель
Генерация 3D-сцен с реалистичным рендером заполнения цилиндрической трубки прозрачной жидкостью под разными углами.

## Параметры трубки
- Форма: цилиндрическая полая трубка
- Внутренний диаметр: 19.5 мм
- Высота: 100 мм
- Толщина стенок: 1 мм
- Нижнее основание: закрыто стенкой 1 мм
- Верх: открыт
- Ориентация: вертикальная
- Материал: прозрачный пластик

## Рендер
- Движок: Cycles (CPU, GPU нет)
- Эффекты: блики, прозрачность, каустики, поверхностное натяжение, мениск, капли

## Этапы

### 1. Геометрия трубки (профиль со скруглениями, revolve, полость)
Создание трубки через `bpy.ops.mesh.primitive_cylinder_add` с разницей диаметров,
или через `bpy.ops.mesh.primitive_torus_add` для скруглённых кромок.
Использовать `bpy.ops.object.make_single_user` и модификаторы (Bevel, Solidify).
Альтернатива: построение профиля в 2D и `bpy.ops.object.add` + `bpy.ops.object.make_primitive` с `bmesh` для точного профиля со скруглёнными кромками, затем `bpy.ops.mesh.primitive_cylinder_add` → extrude → boolean для полости.
Лучший подход: `bmesh` для построения точного профиля (внешний радиус 10.75, внутренний 9.75, скругления на краях), затем `bpy.ops.mesh.extrude` вдоль оси Z.

### 2. Объём жидкости
- Горизонтальная плоскость уровня, отсекающая цилиндр (boolean/cut)
- Подбор уровня по целевому объёлу: итерационный метод (бисекция), объём = π × r² × h
- Угол наклона трубки: вращение объекта + плоскость уровня всегда горизонтальная в мировых координатах

### 3. Мениск и капли
- Мениск: кривая Каби — подъём жидкости по стенке из-за поверхностного натяжения
- Реализация через деформацию верхней грани (shrinkwrap/displace modifier)
- Капли на внешней поверхности: мелкие сферы, распределённые случайно

### 4. Материалы
- Прозрачный пластик: `bsdf_glass` + `bsdf_transparent`, IOR ~1.49 (PMMA/акрил), roughness 0.0
- Жидкость: `bsdf_glass` с объёмным поглощением (`volume_absorption`), IOR ~1.33 (вода)
- Параметры: цвет, поглощение, толщина пути

### 5. Студийная сцена
- Свет: 3-4 источника (key, fill, rim), возможно HDRI
- Фон: однотонный или градиент
- Камера: настройка фокусного расстояния, позиции, фокуса
- Cycles: каустики (`caustics`), бодибус (`body_caustics`), высокий sample count, denoising

### 6. CLI-обвязка
- Скрипт-интерфейс: параметры (угол наклона, объём заполнения, тип жидкости, угол камеры)
- Пакетный рендер: серия кадров с разными параметрами
- Экспорт: `.blend` (исходник), `.glb` (экспорт), `.png` (рендер)

### 7. Тестовые рендеры
- Рендер под разными углами
- Проверка качества (блики, прозрачность, каустики)
- Калибровка параметров

## Среда
- Blender 4.3.2
- Debian 13 (trixie)
- Cycles CPU (GPU нет)
