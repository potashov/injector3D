# AGENTS.md — injector3D

Headless-Blender проект: генерирует 3D-сцену трубки с жидкостью и рендерит
её под 5 углами. Это **не обычный Python-пакет**: модули импортируют `bpy`,
поэтому запускать их нужно только внутри Blender, а не через `python`.

## Команды

```bash
# Рендер пункта плана (номер -> output/<N>/ и префикс файлов)
blender --background --python injector3d/create_scene.py -- 4

# Числовая самопроверка жидкости (единственный автотест в репозитории)
blender --background --python check_liquid.py

# Диагностика CUDA/GPU
blender --background --python check_cuda.py
blender --background --python check_build_cuda.py
blender --background --python gpu_info.py
```

Тестового фреймворка, линтера и typecheck нет — проверка = успешный прогон
`check_liquid.py` (assert'ы + код возврата) и рендер без исключений.

## Версия Blender — проверить первой

Проект написан под **Blender 4.3.2** (имена сокетов `Transmission Weight`,
AgX и т.п.). В текущем окружении `/usr/bin/blender` — **3.4.1**, на котором
`materials.py` упадёт. Перед запуском сверяйте `blender --version` и
используйте сборку 4.3.2, если она доступна.

## Архитектура

- `injector3d/create_scene.py` — entry-point: сцена → трубка → валидация →
  жидкость/материалы → рендер.
- `injector3d/config.py` — все параметры и *все* размеры в мм; в метры
  переводятся через `MM = 0.001`. Не смешивайте мм и Blender-юниты.
- `injector3d/liquid.py` — меш жидкости = полость ∩ `z_world <= level`.
  Меш строится **в мировых координатах** и пересобирается на каждый наклон
  через callback `on_tilt` из `render.py`; объект жидкости намеренно **не**
  дочерний трубке, иначе уровень наклонялся бы вместе с ней.
  Свободная поверхность — мениск: срез на уровне кромки контакта и
  радиальная сетка (`MENISCUS_RINGS`); при наклоне кромка эллиптическая,
  но сама поверхность остаётся горизонтальной. Для клина у дна/перелива —
  плоский fallback.
- `injector3d/meniscus.py` — солвер Юнга-Лапласа (РК4 + бисекция по ζ(0)),
  профиль считается для радиуса меша `INNER_RADIUS - CLEARANCE` и
  кэшируется в `liquid._MENISCUS_CACHE`.
- `check_liquid.py` проверяет V(θ)=const, объём с мениском, горизонтальность
  кромки и manifold на краевых случаях; это единственный автотест.
- `injector3d/render.py` — 5 ракурсов из `config.TILT_VARIANTS`; имена
  `<step>_<ракурс>_<timestamp>.png|.blend`.
- `reports/step*.md` — отчёты по пунктам плана; `PLAN.md`, `CHANGELOG.md`,
  `TODO_meniscus_drops.md` — актуальный контекст и известные проблемы.

## Стадии и артефакты

- Номер пункта после `--` управляет не только именами, но и составом сцены:
  жидкость с пункта 2, материалы с пункта 4. Без номера используется `1`.
- `output/<N>/*.png` **отслеживаются git** как результат работы;
  `.blend`/`.blend1` игнорируются. Не удаляйте чужие рендеры и не считайте
  `output/` временным каталогом.
- Один прогон = 5 кадров 1024×1280 @ 128 сэмплов (GPU ~3–12 с/кадр, CPU
  14–25 с/кадр; есть `RENDER_TIME_LIMIT_S = 75`). Полная серия небесплатна.

## Особенности Blender 4.3 / окружения

- Настройки Cycles только через
  `bpy.context.preferences.addons['cycles'].preferences`, не `preferences.cycles`.
- `MeshEdge.link_faces` и `Mesh.bound_box` в 4.3 недоступны — работать через
  `bmesh` (см. `validate_tube`).
- OpenImageDenoise в headless-сборке Debian отсутствует: денуазинг включается
  условно через `_safe_set`, иначе рендер падает с «Failed to denoise».
  AgX и `AgX - Medium High Contrast` при этом работают.
- CUDA включается для дискретных NVIDIA (`config.GPU_DEVICE_FILTER`); если
  GPU нет — обязателен fallback `cycles.device = 'CPU'`.
- Верх трубки открыт: boundary-рёбра допустимы только на верхней кромке.
